# makelove × вы — коллаборации 2027

Статичный сайт: главная с карточками и календарём, страницы коллаб и OnePager 16:9.

## Структура
- `index.html` — главная (коллаборации → календарь → заявка)
- `kollab.html#<id>` — страница коллабы (шапка → OnePager → лонгрид)
- `onepager.html#<id>` — чистый лист 1920×1080 для выгрузки в PDF
- `data.js` — **весь контент**: периоды, тексты карточек, слоты OnePager (`op`), лонгрид (`page`), цвета темы (`theme`)
  - `SHOW_PRICES` — включает цены
  - `SITE_URL` — адрес сайта: на него ведут кнопка «Принять участие» и QR в PDF
- `pdf/<id>.pdf` — готовые OnePager (пересобираются после смены `SITE_URL` или текстов)
- `fonts/` — Articulat CF (лицензия makelove), Onest и Fira Mono (OFL, подмножество кириллица+латиница) — всё с сайта, без Google Fonts; `img/` — фото и логотипы

## GitHub Pages
Залить содержимое папки в корень репозитория → Settings → Pages → Deploy from branch (`main`, `/root`).

Форма заявки отправляет письма на `info@makeloveagency.ru` через formsubmit.co (адрес — `FORM_EMAIL` в data.js).
После первой заявки на этот ящик придёт письмо FormSubmit «Activate Form» — по ссылке в нём нужно один раз подтвердить, после этого заявки приходят автоматически.
